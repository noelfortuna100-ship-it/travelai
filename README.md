# 🌊 TravelAI – AI iskalnik potovanj (učni prototip)

Delujoča Python/Streamlit aplikacija za predmet IT podpora menedžmentu.

✅ Večkriterijska primerjava potovanj, izračun skupnih stroškov za vse potnike, brezplačna demonstracija.
✅ Učni model strojnega učenja (TF-IDF + logistična regresija) prepoznava slovenske želje.
⚠️ Vse cene, hoteli, leti in termini so izmišljeni demonstracijski podatki. Ne omogoča rezervacij.

Za objavo glej [NAVODILA_ZA_OBJAVO.md](NAVODILA_ZA_OBJAVO.md).

Lokalni zagon:
```bash
pip install -r requirements.txt
streamlit run app.py
```
